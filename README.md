# E-commerce-Website-CSE-3100-project

##  Project Overview

This project is a **full-stack e-commerce web application** designed to provide a **responsive, secure, and scalable online shopping experience**. The system emphasizes interactive user features, efficient server-side data handling, and secure transaction processing, making it suitable for real-world e-commerce use cases.

##  Objective

To design and implement a **responsive, secure, and scalable e-commerce platform** that delivers a smooth user experience through dynamic interactions, backend logic, and secure authentication and transaction workflows.

---

##  Technology Stack

* **Backend:** PHP
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** MySQL

---

##  Key Features

###  User Features

* Secure user registration and login with **password hashing**
* Product browsing with **search** option
* Server-side **cart management**
* Checkout and **order placement workflow**
* Payment confirmation and **order tracking**
* User profile management and order history

###  Admin Features

* Secure admin authentication
* **Full CRUD operations** for:

  * Products
  * Categories
  * Brands
* User management
* Order and payment monitoring
* Invoice-based order status tracking

---

##  System Architecture

The application follows a **modular PHP architecture**, separating:

* **Database connectivity** (centralized connection handling)
* **Business logic** (reusable functions and server-side processing)
* **Presentation layer** (UI components and pages)


---

##  Security Considerations

* Passwords are stored using **secure hashing techniques**
* Session-based **role management** for users and administrators
* Server-side validation for cart, order, and payment operations
* Controlled access to admin functionalities

---

##  Database Design

* Relational MySQL database
* Separate tables for users, products, categories, brands, orders, payments, and cart details
* **Invoice-based order tracking** to ensure accurate order–payment mapping
